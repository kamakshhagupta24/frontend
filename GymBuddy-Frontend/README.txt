GYMBUDDY FRONTEND - UPDATED FLOW

1. Extract GymBuddy-Frontend.zip.
2. Open the extracted GymBuddy-Frontend folder in VS Code.
3. Open index.html with Live Server.
4. Public landing page:
   Home, About, Features, Log In, Sign Up.
5. After submitting the demo login/signup forms, the preview navigates to dashboard.html.
6. Dashboard links to Profile, Find Buddies, Requests, Chat, Gyms, and Workouts.
7. Shared files: style.css and script.js.

IMPORTANT:
- This is a frontend-only demo rebuild. It does not include or modify your existing backend.
- Login/signup redirect to the dashboard for preview only; no real authentication occurs.
- Buddy requests and profile saves are not persisted or connected to the server.
- Chat messages only appear in the current browser page.
- Sample profiles, requests, gyms, and workouts are illustrative.
- Images are intentionally omitted for now.
